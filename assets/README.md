# Brand assets

Edgar is the SoftEdge mascot, a hedgehog. All files here are MIT licensed, like the code.

- `mascot.svg`: Edgar standing, with a rising line for an edge.
- `mascot-curled.svg`: Edgar curled into a ball, with a flat line for no edge.
- `logo.svg`: Edgar's head in a circle, for icons down to 32 px.
- `banner.svg`: logo, wordmark and tagline for the repository header. It has its own background, so it reads on light and dark GitHub themes.
